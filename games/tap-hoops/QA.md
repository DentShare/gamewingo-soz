# Проверка веб-прототипа — 12 октября 2026

Баскетбол добавлен в каталог как веб-пилот без наград. Это не акт готовности банковского WebView.

## Выполнено

- `npm run check:back`: все 18 игр, код выхода 0; выход в каталог относительный и одинаково работает на preview/production-доменах.
- TypeScript, сборка Vite и 19 юнит-тестов: фиксированная физика, реальные траектории, отскоки, зачёт только сверху, отсутствие повторного зачёта, лимиты времени/очков, сложность, RU/UZ, мост и изоляция личных рекордов от кошелька.
- 13 браузерных сценариев на 390×844 и 360×740: учебный бросок, одиночное нажатие без автоповтора, чистая корзина и прибавка времени, пауза/PAUSE/RESUME, удержание пробела, настоящий history.back, рестарт, итог, UZ (DPR 2). Дополнительный контекст reduced-motion проверяет рабочую физику/попадание без вращения, растяжения мяча и качания сетки. Ошибок страницы и внешних запросов нет.
- Визуальный просмотр меню и попадания; разметка площадки ограничена её границами. Сетка реагирует на попадание; декоративное движение отключается при reduced-motion.
- Общий звук; оригинальная процедурная графика. Билд около 1,62 МиБ, gzip около 0,38 МиБ.
- Итог сохраняет только личные испытания и рекорд через game-progress. Нет submitScore, начисления наград, дневных заданий или финансовых API.
- Собранный каталог проверен через `node scripts/check-web-pilots.mjs`: карточка/иконка, возраст 6–9, пометка прототипа, реальные учебный тап и старт, пауза, отсутствие наград. Тестовая телеметрия изолирована от живого монитора.
- 7 тестов каталога, включая исключение обоих пилотов из рекомендаций заданий дня и рекорда недели.

## Ещё требуется

Плейтест сложности, физические iOS/Android WebView, слабый Android, реальные safe-area и загрузка на 3G. FPS и время загрузки на этих устройствах не измерены. Серверный скоринг/антифрод и награды не подключены.

Запуск: `npm run dev -w @gamewingo/tap-hoops`, адрес `http://127.0.0.1:4182/`.
Повторная проверка: `npm test -w @gamewingo/tap-hoops`, `npm run typecheck -w @gamewingo/tap-hoops`, `npm run build -w @gamewingo/tap-hoops`, `npm run qa -w @gamewingo/tap-hoops`.
