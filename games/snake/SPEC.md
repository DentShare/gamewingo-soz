# SPEC: Змейка (snake)

## 1. Идентификация

- **slug** (папка / gameId): `snake`
- **Рабочее название:** Змейка / Ilon
- **Механика в одном предложении:** классическая аркадная змейка — ползёт по сетке, ест еду, растёт и ускоряется; врезался в стену или в себя — партия окончена.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser (ни одного бинарного ассета, кроме шрифта Rubik и фавикона)

## 2. Механика

- **Жанр:** аркада «зашёл и играешь» — в меню нет уровней, одна кнопка «Играть», на экране результата «Ещё раз» мгновенно запускает новую партию.
- **Цель игрока:** съесть как можно больше еды и не врезаться.
- **Поле:** сетка 15×20 клеток по 24 px (360×480), вписана в портрет 400×720.
- **Управление:** свайпы по экрану (порог 24 px, доминирующая ось; точка отсчёта сдвигается — можно вести пальцем не отрывая) + стрелки/WASD на клавиатуре. Разворот на 180° запрещён.
- **Буфер ввода:** до 2 команд поворота в очереди — свайп чуть раньше тика не теряется, применяется на следующем тике.
- **Старт партии:** змейка стоит и ждёт первого свайпа/стрелки (подсказка «Свайпните, чтобы начать») — игрок не врежется, пока осматривается.
- **Скорость:** тик 190 мс в начале, −5 мс за каждую съеденную еду, пол — 90 мс (`tickMs()` в `src/core/snake.ts`).
- **Длительность партии:** 30–120 сек.
- **Как считается score:** `eaten * 100` — см. `src/core/score.ts`. Начисление баллов — только на сервере.
- **Максимально возможный score:** теоретический максимум партии = `(15*20 − 5) * 100 = 29 500`; антифрод-потолок в клиенте — `MAX_SCORE = 100 000` (`clampScore()` перед отправкой). Сервер валидирует независимо: score ≤ 29 500, `score % 100 === 0`, `durationMs ≥ eaten * 90 мс`.
- **Прогресс/уровни:** уровней нет; лучший счёт устройства в localStorage (`snake:best`), обучение — один раз (`snake:onboarded`).

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога; `theme.primary`/`background` применяются из INIT. Змейка — зелёная (#2fb84c), еда — оранжевая ягода.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** векторная змейка (сегменты со скруглением, голова с глазами) — в меню и на поле.
- **Языки:** RU / UZ, все строки через `src/i18n` (парность ключей проверяется тестом).
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при первом свайпе/стрелке (`session.start()`, тогда же стартует таймер партии)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {eaten, length}`
- [x] `GAME_EXIT` — ссылка «‹ К играм» в меню

Сервер получает `submitScore` c meta `{eaten, length}` — начисление и валидация только на сервере.

## 5. Производительность

- **Билд:** ~1.5 МБ (phaser 1.3 МБ + код 40 КБ) — в бюджете < 5 МБ (цель < 2 МБ).
- **60 fps:** сегменты змейки берутся из пула `Phaser.GameObjects.Image` с общей сгенерированной текстурой; на тике меняются только позиции/тинты, объекты не пересоздаются. Между тиками позиции интерполируются — движение плавное при редких тиках.
- **Поле** рисуется один раз в статический `Graphics` (подложка + «шахматка» + рамка).

## 6. Обучение

3 шага поверх настоящего поля (`src/game/onboarding.ts`, затемнение + «дырка» + пульсирующая рамка):

1. подсветка змейки — «Свайпайте в любую сторону — змейка поползёт туда»;
2. подсветка еды — «Съедайте еду: змейка растёт, очки прибавляются»;
3. подсветка границ поля — «Врезались в стену или в себя — конец. Чем длиннее, тем быстрее».

Показывается один раз при первой партии (`snake:onboarded`) и по кнопке «Как играть» из меню. Во время обучения свайпы и стрелки заблокированы.

## 7. Тесты

`npm test -w @gamewingo/snake` — 23 теста:

- `src/core/snake.test.ts` — движение, рост и счёт, еда никогда не на теле (3000 итераций с фиксированным seed), запрет разворота, буфер ввода, стены и самопересечение, «после конца ничего не меняется», убывание `speedMs()` с полом, детерминированность по seed, потолок счёта;
- `src/i18n/i18n.test.ts` — парность ключей ru/uz, обязательные ключи, совпадение плейсхолдеров;
- `src/game/roundTimer.test.ts` — учёт пауз в длительности партии.
