# SPEC: Полёт (flyer)

## 1. Идентификация

- **slug** (папка / gameId): `flyer`
- **Рабочее название:** Полёт / Parvoz
- **Жанр:** аркада (endless, «зашёл и играешь»)
- **Механика в одном предложении:** герой держится в воздухе тапами и пролетает сквозь проёмы в стенах, пока не заденет препятствие.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (структура взята из `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser + системные эмодзи (ничего не бандлим). Механика реализована с нуля, чужой код и ассеты не используются.

## 2. Механика

- **Цель игрока:** пролететь как можно больше проёмов.
- **Управление:** тап в любом месте экрана (на десктопе — пробел / стрелка вверх); mobile-first, portrait 400×720.
- **Длительность партии:** 20–60 сек, смерть мгновенная (стена, пол или потолок).
- **Старт:** герой висит на месте и не падает до первого тапа — подсказка «Тапните, чтобы взлететь».
- **Физика (`src/core/flight.ts`, фиксированный шаг 100 Гц):** гравитация 1500 px/с², импульс тапа −430 px/с, предел падения 700 px/с.
- **Препятствия:** стены шириной 62 px с проёмом 190 px, шаг 230 px, первый проём выровнен по стартовой высоте героя (бесплатный). Высота проёма случайна (mulberry32), геометрия — константы поля 400×720, пол на y=636.
- **Сложность:** скорость стен растёт с 150 до 260 px/с (+2.2 px/с за каждый пройденный проём) — то есть растёт и частота препятствий.
- **Как считается score:** `passed * 100 + min(200, sec*2)` — см. `src/core/score.ts`.
- **Максимально возможный score:** серверный антифрод-потолок **100000** (`MAX_SCORE`); дополнительная проверка сервера — `score ≤ passed*100 + 200` и правдоподобность `durationMs` (≈1.5 сек на проём и меньше по мере разгона). Начисление баллов — ТОЛЬКО на сервере.
- **Прогресс:** бесконечный режим; личный рекорд в localStorage (`flyer:best`), флаг обучения — `flyer:onboarded`.
- **Производительность:** пул из 5 контейнеров-стен, 4 облака и полосы земли переиспользуются; в кадре только меняются координаты, новые объекты не создаются.

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) в меню и на результате; игровое поле — небо (градиент) + зелёные стены + земля. `theme.primary`/`background` применяются из INIT.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** векторный бейдж-круг с эмодзи 🚀 (наклон по вертикальной скорости).
- **Языки:** RU / UZ, все строки через `src/i18n` (наборы ключей ru/uz проверяются тестом).
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.
- **Обучение:** 3 шага поверх настоящего экрана игры (герой → проём → счёт), показывается один раз при первой партии и по кнопке «Как играть».

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [x] `GAME_EXIT` — по ссылке «‹ К играм» в меню
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {passed}`

Сервер получает `submitScore` c meta `{passed}` — начисление и валидация только на сервере.
Реальных денег и выводов в игре нет (App Store Guideline 4.7), только виртуальные баллы.
