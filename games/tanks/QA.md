# Проверка веб-прототипа — 12 октября 2026

Не является актом готовности банковского WebView. Проверка на компьютере, без физических iOS/Android WebView. Веб-публикация — только прототип без наград.

## Пройдено

- `npm run check:back`: все 18 игр, код выхода 0; исправлен выход пилотов в относительный каталог, без жёсткой привязки к production-домену.
- `npm run typecheck -w @gamewingo/tanks`.

Правила, столкновения, первая стена на пути пули, броня, щиты, очки, лимиты, детерминированность, независимые пальцы, словари и мост без API наград. Дополнительный тест подтверждает отсутствие записи дневных заданий/статистики и неизменность кошелька при сохранении всех 15 личных испытаний. Регрессия боковой стрельбы: четыре направления, кадр из нескольких шагов симуляции и отмена при уходе цели. Обходчик проходит оба боковых маршрута на исходной карте; проверены расписание выбора, полная остановка симуляции в длинном кадре, ручная активация, ремонт без потери заряда при полной броне, пять активных секунд защиты только танка, замена слота и сброс сил между боями.

Настоящие события двух касаний через CDP, обучение быстрым тапом, отпускание обоих пальцев, остановка времени в паузе, PAUSE/RESUME, history.back, рестарт, итог и узбекский интерфейс. Ошибок страницы/console.error и внешних запросов не обнаружено. Закрытие браузера ограничено по времени и работает только с собственным процессом QA.

## Ограничения

- В прежнем запуске закрытие тестового браузера задерживалось. QA запускает Vite напрямую по dev-конфигу игры, без npm/cmd-дерева; закрытие браузера ограничено по времени, завершаются только собственные процессы. Ошибки игры по-прежнему проваливают прогон.
- Встроенный просмотр через CUA недоступен: ошибка запуска Windows sandbox. Проверка выполнена отдельным тестовым Chromium через существующую зависимость репозитория, не управлением пользовательским браузером.
- Проверки физического мультитача, safe-area в реальных WebView, слабого Android, загрузки на 3G и плейтест баланса ещё нужны.
- Веб-каталог содержит пилот `prototype`, `practice`, `rewardsEnabled: false`, без лидерборда/streak. Серверная экономика не подключена. Финальные растровые ассеты, охотник, скорострельность, усиленный снаряд и EMP не подключены. Новых генераций Kling не было.

## Повторить

В одном терминале `npm run dev -w @gamewingo/tanks`, в другом `npm run qa -w @gamewingo/tanks`. Для браузерного теста нужен установленный Chrome/Edge или `CHROMIUM_PATH`; браузеры автоматически не скачиваются. Скриншоты QA генерируются локально и не входят в билд.
