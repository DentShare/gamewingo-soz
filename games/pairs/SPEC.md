# SPEC: Найди пару (pairs)

## 1. Идентификация

- **slug** (папка / gameId): `pairs`
- **Рабочее название:** Найди пару / Juftini top
- **Механика в одном предложении:** классическое мемори — открывать карточки по две и находить пары за минимум ходов.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/soz`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser + системные эмодзи (ничего не бандлим)

## 2. Механика

- **Цель игрока:** найти все пары карточек.
- **Управление:** тап по карточке; mobile-first, portrait 400×720.
- **Длительность партии:** 30–120 сек (по уровню).
- **Уровни:** easy 3×4 (6 пар), medium 4×5 (10 пар), hard 5×6 (15 пар).
- **Как считается score:** `round(pairs*400*(0.4+0.6*pairs/moves)) + max(0, 600 − sec*4)` — см. `src/core/score.ts`.
- **Максимально возможный score:** `pairs*400 + 600` (hard: 6600) — для серверного антифрод-лимита.
- **Прогресс/уровни:** три уровня; лучший результат уровня в localStorage (`pairs:best:<level>`), звёзды 1–3 по точности.

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога, `theme.primary`/`background` применяются из INIT.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** системные эмодзи-животные на карточках; рубашка — вектор.
- **Языки:** RU / UZ, все строки через `src/i18n`.
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {level, moves}`

Сервер получает `submitScore` c meta `{level, pairs, moves}` — начисление и валидация только на сервере.
