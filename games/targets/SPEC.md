# SPEC: Меткий глаз (targets)

## 1. Идентификация

- **slug** (папка / gameId): `targets`
- **Рабочее название:** Меткий глаз / Nishonga ur
- **Механика в одном предложении:** аркада на реакцию — за 60 секунд сбить как можно больше вспыхивающих целей, не разрывая серию.
- **Жанр:** аркада «зашёл и играешь» — без уровней и настроек, одна кнопка «Играть», мгновенный рестарт.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser + системные эмодзи (ничего не бандлим)

## 2. Механика

- **Цель игрока:** набрать максимум очков за одну минуту.
- **Управление:** одиночный тап по цели; mobile-first, portrait 400×720.
- **Длительность партии:** ровно 60 000 мс (`ROUND_MS`), обратный отсчёт крупно в HUD. Перед стартом — отсчёт «3 · 2 · 1».
- **Поле:** `FIELD = {x: 12, y: 104, w: 376, h: 580}` — не заходит под HUD; цели всегда целиком внутри поля.
- **Цели:** круглые, вспыхивают в случайных местах, живут ограниченное время (`ttl`), плавно появляются и гаснут (масштаб + прозрачность).
  - радиус: диапазон от `30…46` в начале до `20…30` в конце партии;
  - `ttl`: `1700 → 950 мс` по ходу партии;
  - пауза между спавнами: `800 → 420 мс`;
  - одновременно на поле ≤ 5 (фактически 2–3);
  - каждая 10-я цель — **золотая**: мельче, живёт 0.62 × ttl, очки ×3.
- **Попадание:** цель лопается (раздувается и исчезает) + всплывающие «+N».
- **Промах по пустому месту:** без штрафа по очкам (игра дружелюбная), но обнуляет серию. Показывается тихая волна.
- **Погасшая сама цель:** тоже обнуляет серию.
- **Серия (комбо):** попадания подряд без промаха и без «протухших» целей. Множитель `min(5, 1 + floor(combo/4))` — до **×5**, крупно в HUD.
- **Темп:** со временем цели мельчают и живут меньше — плотность растёт линейно по `progress = elapsed / 60 000`.

### Очки за одну цель

```
sizeFactor = clamp01((46 − r) / (46 − 18))     // 0 крупная … 1 мелкая
base       = 10 + 30 × sizeFactor              // 10…40
reaction   = clamp01(1 − age / ttl)            // 1 мгновенно … 0 на излёте
speed      = 0.55 + 0.9 × reaction             // 0.55…1.45
points     = max(1, round(base × speed × (золотая ? 3 : 1)) × множитель)
```

Максимум с одной цели: `round(40 × 1.45) × 3 × 5 = 870`.

## 3. Счёт и антифрод

- **Итоговый score** берётся целиком из ядра (`TargetsGame.score`), см. `src/core/targets.ts`.
- **Максимум целей за партию:** `MAX_TARGETS_PER_ROUND = 102` (интеграл темпа 800→420 мс за 60 с). Больше попаданий за минуту физически невозможно.
- **Теоретический максимум счёта:** ≈ 35 400 (все цели мельчайшие, мгновенная реакция, серия ×5 всю партию).
- **Практический серверный потолок:** `SCORE_CAP = 50 000` (`src/core/score.ts`) — запас на ретюнинг темпа. Всё выше сервер обязан отклонить.
- **Длительность партии фиксированная:** сервер должен требовать `durationMs ≥ 58 500` (`MIN_ROUND_MS`) и отклонять партии короче.
- **Игра НИКОГДА не начисляет баллы.** Она отправляет `score` + `durationMs` + `sessionId` + meta `{hits, maxCombo}`; валидация, антифрод (лимит частоты партий, потолок счёта, время сессии) и начисление — только на сервере.
- Дополнительная серверная проверка на согласованность: `hits ≤ 102`, `maxCombo ≤ hits`, `score ≤ hits × 870`.

## 4. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон `#fbebe1`, primary `#f26522`) — общая для каталога; `theme.primary`/`background` применяются из INIT.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Ключевой арт:** векторная мишень (три круга Phaser), золотая цель — тёплый янтарь; эмблема меню — системное эмодзи 🎯.
- **Языки:** RU / UZ, все строки через `src/i18n` (`ru.json` / `uz.json`, парность ключей покрыта тестом).
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤ 700 мс.

## 5. Экраны

- **MainMenu:** ссылка «‹ К играм», эмблема 🎯, заголовок, переключатель RU/UZ, **«Играть»** (primary), рекорд, «Как играть».
- **Game:** HUD — счёт (слева), крупный обратный отсчёт (справа сверху), серия ×N (справа); поле с целями; кнопка «Назад».
- **GameOver:** «Время вышло!», счёт, «Попаданий: N · Серия: M», «Новый рекорд!» + конфетти при рекорде, **«Ещё раз»** (primary, сразу новая партия) и «В меню», таблица лидеров.

## 6. Обучение

Три шага поверх настоящего экрана (`src/game/onboarding.ts`, стиль каталога — затемнение `0x241a12` α 0.74, «дырка», пульсирующая рамка, белая карточка, точки, «Далее»/«Понятно», «Пропустить»):

1. на поле зажигается настоящая цель → «Бейте по целям, пока они не исчезли»;
2. подсветка строки счёта/серии в HUD → «Попадания подряд поднимают множитель — очков всё больше»;
3. подсветка крупного таймера → «У вас 60 секунд. Промах не штрафует, но сбивает серию».

Показывается из меню («Как играть») и один раз при первой партии (`targets:onboarded`); во время обучения тапы по целям заблокированы.

## 7. Производительность

- **Пул объектов:** 12 целей, 10 всплывающих «+N», 6 волн промаха — во время партии ничего не создаётся и не уничтожается.
- **HUD:** `setText` только при изменении значения, не каждый кадр.
- **Шаг ядра:** нарезка по 50 мс — темп не зависит от частоты кадров; `delta` ограничена 50 мс (защита от сворачивания WebView).
- **Размер прод-билда:** ≈ 1.44 МБ (бюджет < 5 МБ, цель < 2 МБ).

## 8. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии, после отсчёта (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {hits, maxCombo}`
- [x] `GAME_EXIT` — по ссылке «‹ К играм» в меню
- [x] `PAUSE` / `RESUME` — партия и таймер замирают

Сервер получает `submitScore` c meta `{hits, maxCombo}` — начисление и валидация только на сервере.
