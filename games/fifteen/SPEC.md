# SPEC: Пятнашки (fifteen)

## 1. Идентификация

- **slug** (папка / gameId): `fifteen`
- **Рабочее название:** Пятнашки / Boshqotirma 15
- **Механика в одном предложении:** классические пятнашки — сдвигать плитки в пустую клетку и собрать числа по порядку за минимум ходов.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser + системные эмодзи (ничего не бандлим)

## 2. Механика

- **Цель игрока:** собрать плитки 1..N−1 по порядку (пустая клетка — в правом нижнем углу).
- **Управление:** тап по плитке, соседней с пустой клеткой; на десктопе — стрелки клавиатуры (стрелка двигает плитку в пустую клетку с противоположной стороны: ↑ — плитка под пустой уезжает вверх). Mobile-first, portrait 400×720.
- **Длительность партии:** 30–300 сек (по уровню).
- **Уровни:** `3x3` «Детский» (плитки 1–8), `4x4` «Классика» (плитки 1–15).
- **Генерация расклада:** случайное блуждание из собранного состояния — K валидных ходов без немедленной отмены предыдущего (3×3 → 80, 4×4 → 160), что гарантирует решаемость; если поле случайно собралось — блуждание повторяется. См. `src/core/board.ts`.
- **Как считается score:** `max(100, base − moves*5 − sec*2)`, где `base` = 2000 (3×3) / 4000 (4×4) — см. `src/core/score.ts`. Начисляется только за собранное поле.
- **Максимально возможный score:** `base` уровня (3×3: 2000, 4×4: 4000) — для серверного антифрод-лимита.
- **Прогресс/уровни:** два уровня; лучший результат уровня в localStorage (`fifteen:best:<level>`).

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога, `theme.primary`/`background` применяются из INIT.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** плитки — векторные скруглённые квадраты с цифрами (стиль карточек каталога), эмодзи 🧩 в меню.
- **Языки:** RU / UZ, все строки через `src/i18n`.
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {level, moves}`

Сервер получает `submitScore` c meta `{level, moves}` — начисление и валидация только на сервере.
