# SPEC: Мини-судоку (sudoku-kids)

## 1. Идентификация

- **slug** (папка / gameId): `sudoku-kids`
- **Рабочее название:** Мини-судоку / Mini sudoku
- **Механика в одном предложении:** детское судоку на сетках 4×4 и 6×6 — заполнить все клетки так, чтобы цифра не повторялась в строке, столбце и блоке.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser + системные эмодзи (ничего не бандлим)

## 2. Механика

- **Цель игрока:** заполнить сетку без конфликтов; паззл всегда с единственным решением (генератор с решателем-счётчиком).
- **Управление:** тап по клетке — выделение (подсветка строки/столбца), тап по цифре внизу — ввод; ластик стирает; mobile-first, portrait 400×720.
- **Длительность партии:** 1–6 мин (по уровню).
- **Уровни:** `easy4` 4×4 (блоки 2×2, ≥8 данных из 16), `easy6` 6×6 (блоки 2×3, ≥20 данных из 36), `hard6` 6×6 (≥15 данных из 36).
- **Подсказки:** максимум 3 за партию (💡 вписывает правильную цифру в выделенную или случайную пустую клетку), счётчик виден на кнопке.
- **Конфликты:** подсвечиваются мягким красным сразу при вводе.
- **Как считается score:** `max(100, base − sec*2 − hints*300)`, где base: easy4 1500, easy6 3000, hard6 4500 — см. `src/core/score.ts`.
- **Максимально возможный score:** `base` уровня (hard6: 4500) — для серверного антифрод-лимита.
- **Прогресс/уровни:** три уровня; лучший результат уровня в localStorage (`sudoku:best:<level>`).

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога, `theme.primary`/`background` применяются из INIT; данные (givens) — тёмный жирный текст на тонированном фоне, ввод игрока — оранжевый, конфликт — мягкий красный.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** 🧩 в меню; доска и клавиши — вектор.
- **Языки:** RU / UZ, все строки через `src/i18n`.
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {level, hints}`

Сервер получает `submitScore` c meta `{level, hints}` — начисление и валидация только на сервере.
