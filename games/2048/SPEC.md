# SPEC: 2048 (2048)

## 1. Идентификация

- **slug** (папка / gameId): `2048`
- **Рабочее название:** 2048
- **Механика в одном предложении:** классический 2048 — свайпами сдвигать плитки 4×4, сливать одинаковые и собрать плитку 2048.
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — векторные примитивы Phaser (ничего не бандлим)

## 2. Механика

- **Цель игрока:** собрать плитку 2048 (игра продолжается и дальше) и набрать максимум очков до конца ходов.
- **Управление:** свайп в четырёх направлениях (порог 24 px, доминирующая ось) + стрелки клавиатуры; mobile-first, portrait 400×720.
- **Длительность партии:** 1–10 мин.
- **Правила:** свайп сдвигает все плитки; одинаковые соседние по направлению движения сливаются, каждая плитка — максимум один раз за ход; после каждого результативного хода спавн новой плитки на случайной пустой клетке (2 с p=0.9, 4 с p=0.1); проигрыш — нет возможных ходов; 2048 — флаг won (тост один раз, игра продолжается).
- **Как считается score:** сумма номиналов всех слитых плиток (стандарт 2048) — считается ядром `src/core/grid.ts`, на сервер передаётся готовым.
- **Максимально возможный score:** практический потолок для серверного антифрод-лимита — **400000**.
- **Прогресс/уровни:** один режим; лучший счёт в localStorage (`2048:best`).

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога, `theme.primary`/`background` применяются из INIT. Плитки — тёплая шкала от кремового (2) к оранжевому WinGo (2048) и тёмно-коричневому (4096+).
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** плитки-вектор (Phaser Graphics), логотип-плитки в меню; ничего не бандлим.
- **Языки:** RU / UZ, все строки через `src/i18n`.
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.

## 4. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {maxTile, moves}`

Сервер получает `submitScore` c meta `{maxTile, moves}` — начисление и валидация только на сервере
(лимит времени сессии, потолок score 400000, согласованность score ↔ maxTile ↔ moves).

- **Баллы/награды:** виртуальные баллы за счёт партии; решение — сервер.
- **Лидерборд:** есть, глобальный по игре (`leaderboard('2048')`).
- **Стрики:** нет.
