# SPEC: Сортировка (sorting)

## 1. Идентификация

- **slug** (папка / gameId): `sorting`
- **Рабочее название:** Сортировка / Saralash
- **Механика в одном предложении:** детская сортировка — перетаскивать фигурки в корзины по цвету или по форме.
- **Целевой возраст:** 3–6 лет (детский раздел каталога).
- **Источник-шаблон:** официальный стартер Phaser `template-vite-ts` (через структуру `games/pairs`) — см. `docs/LICENSES.md`
- **Лицензия:** MIT (стартер); графика — только векторные примитивы Phaser + системные эмодзи (ничего не бандлим)

## 2. Механика

- **Цель игрока:** разложить 12 фигурок по трём корзинам.
- **Управление:** перетаскивание пальцем (drag & drop) из лотка в корзину; mobile-first, portrait 400×720.
  Крупные зоны касания: фигурка 92 px + запас хита 34 px, корзины 108×140 px у нижнего края.
- **Режимы:**
  - **По цвету** — корзины красная / жёлтая / синяя, форма фигурки случайна и на ответ не влияет.
  - **По форме** — корзины круг / квадрат / треугольник (нейтрального цвета), цвет фигурки случаен и не влияет.
  Так ребёнок учится выделять один признак и игнорировать второй.
- **Длительность партии:** 40–90 сек (12 фигурок).
- **НЕЛЬЗЯ ПРОИГРАТЬ** (ключевое правило жанра):
  - нет таймера обратного отсчёта, нет проигрыша, нет штрафов и вычитания очков;
  - неверная корзина → фигурка мягко возвращается на место, корзина качается,
    правильная корзина на секунду подсвечивается — это подсказка, а не наказание;
  - отпустил мимо корзин → фигурка просто возвращается, ничего не происходит;
  - ошибки влияют только на количество звёзд в конце.
- **Положительная обратная связь:** верный бросок — фигурка «всасывается» в корзину,
  корзина подпрыгивает, зелёная вспышка, счётчик пульсирует; в конце — конфетти и «Молодец!».
- **Как считается score:** `placed*100 + (mistakes === 0 ? 300 : mistakes <= 3 ? 100 : 0)` — см. `src/core/score.ts`.
- **Максимально возможный score:** **1500** (`12*100 + 300`) — жёсткий верхний предел
  для серверного антифрода (`MAX_SCORE` в `src/core/score.ts`).
- **Антифрод (серверные проверки):**
  - `score > 1500` → отклонять;
  - `score % 100 !== 0` и не из множества `{n*100, n*100+100, n*100+300}` → отклонять;
  - `durationMs < 8000` при `placed = 12` → подозрительно (12 перетаскиваний физически быстрее не сделать);
  - `durationMs > 20 мин` → сессия протухла;
  - частота наград: не чаще, чем настроено в программе лояльности.
- **Звёзды:** 3 — без ошибок, 2 — до 3 ошибок, 1 — просто дошёл до конца.
- **Лестница:** 15 уровней в трёх главах по рычагу — «Цвета» (растёт число фигурок, 6 → 14),
  «Формы» (сортировка по форме, 10 → 18), «Ещё корзина» (четвёртая корзина, признак
  чередуется, финал — 20 фигурок по форме). На каждом уровне жёстче ровно один рычаг —
  см. `src/core/levels.ts`. Уровень дня — параметры одного из уровней 8–12 и расклад по зерну от даты.
- **Прогресс:** лучший результат режима в localStorage (`sorting:best:<mode>`), обучение — `sorting:onboarded`.

## 3. Бренд и локализация

- **Палитра:** светлая тема WinGo (персиковый фон #fbebe1, primary #f26522) — общая для каталога,
  `theme.primary`/`background` применяются из INIT. Цвета фигурок: красный #e8453c, жёлтый #f6c026, синий #2f80ed.
- **Шрифты:** Rubik (бандл, сабсеты latin + cyrillic).
- **Маскот / ключевой арт:** 🎨 в меню; фигурки, корзины и лоток — вектор (Graphics).
- **Языки:** RU / UZ, все строки через `src/i18n` (парность ключей проверяется тестом).
- **Сплэш-экран:** нет (мгновенная загрузка), Boot ждёт INIT ≤700 мс.
- **Чёткость:** холст рендерится в `400×720 × DPR`, камера каждой сцены зумлена в DPR,
  всем текстам проставлен `setResolution(DPR)`.

## 4. Обучение

Один шаг на настоящей партии (`runFirstMoveTutorial` из `@gamewingo/game-ui`): поле видно,
обведены фигурка в лотке и её корзина, остальное приглушено; «палец» ездит от фигурки к корзине
(подсказка жеста); внизу полоса «Перетащи фигурку в корзину такого же цвета / такой же формы»
и «Пропустить». Перетаскивание — настоящий ход; первая верно разложенная фигурка закрывает
обучение. Чип прогресса спрятан, часы партии стоят до неё.

Ошибка объясняется в момент первой ошибки строкой `rule.mistake` (`showRuleOnce`,
один раз на устройство) вместе с миганием нужной корзины.

Показывается при первой партии (`sorting:onboarded`) и по «Как играть» из паузы.

## 5. Финтех-слой (события моста)

- [x] `GAME_READY` — при загрузке (Boot)
- [x] `GAME_START` — при старте партии (`session.start()`)
- [x] `GAME_OVER` — в конце партии со `score` и `durationMs`
- [ ] `REWARD_CLAIM` — нет (нет daily-механики)
- [x] `GAME_EVENT` — `round_finished {mode, feature, mistakes}`
- [x] `EXIT` — ссылка «‹ К играм» в меню (`session.exit()`)

Сервер получает `submitScore` c `gameId: 'sorting'` и meta `{level, mode, feature, mistakes}`
(`mode` — `level` | `dailyLevel`, как у всего каталога; `feature` — признак `color` | `shape`) —
начисление и валидация только на сервере, игра баллы не начисляет.
