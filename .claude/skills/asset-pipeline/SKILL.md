# Скилл: asset-pipeline

Картинки — единственное, что реально способно вынести игру за бюджет (правило №7: < 2 МБ).
Скилл превращает «папку с исходниками от дизайнера или из купленного пака» в то, что можно
класть в `public/`: нужный размер, webp, понятный вес и заполненная строка в реестре лицензий.

## 0. Как ассеты попадают в репозиторий

Из этой среды маркетплейсы (craftpix.net, kenney.nl, opengameart.org) закрыты прокси —
скачать пак отсюда нельзя. Файлы приносит пользователь: кладёт архив/папку в репозиторий
или в `/tmp`, дальше работает пайплайн. Это не обходится, это данность окружения.

## 1. Разовая установка sharp

`sharp` намеренно не в `package.json`: он тяжёлый, а нужен раз в несколько недель
и только локально. Ставится без записи в манифест:

```bash
npm i -D sharp --no-save
```

## 2. Прогон

```bash
# папка исходников → папка игры, максимум 512 px по длинной стороне, webp
node .claude/skills/asset-pipeline/scripts/prepare-assets.mjs /tmp/pack games/jigsaw/public/pictures

# посмотреть, что будет, ничего не записывая
node .claude/skills/asset-pipeline/scripts/prepare-assets.mjs /tmp/pack --dry

# квадрат 336×336 с прозрачными полями (картинки пазла) и качеством повыше
node .claude/skills/asset-pipeline/scripts/prepare-assets.mjs /tmp/pack games/jigsaw/public/pictures \
  --max=336 --square --quality=86

# png вместо webp (нужен редко: только если целевой WebView древний)
node .claude/skills/asset-pipeline/scripts/prepare-assets.mjs /tmp/pack out --png
```

Скрипт печатает таблицу «файл — было — стало — экономия», итог по всей папке и
шаблон строки для `docs/LICENSES.md`. Не трогает `.svg`: векторные значки каталога
остаются вектором (см. `docs/ICONS.md`).

## 3. Размеры, которые нужны каталогу

| Что | Размер | Формат |
|---|---|---|
| Картинка пазла | 336 × 336 | webp, quality 86 |
| Спрайт предмета/фишки | 128 × 128 | webp, quality 80 |
| Фон сцены (portrait 400 × 720) | 800 × 1440 | webp, quality 72 |
| Иконка игры в хабе | 96 × 96 | **svg** (не растр) |

Логический холст игр — 400 × 720, реальный экран телефона — до 3× DPR. Отсюда правило:
растр берём вдвое больше отображаемого размера, дальше глаз не видит разницы, а вес растёт.

## 4. После прогона

1. Файлы положить в `games/<slug>/public/<папка>/`, ссылаться относительным путём.
2. Заполнить строку в `docs/LICENSES.md` — **до** коммита файлов, правило №4.
   Скрипт печатает готовый шаблон, остаётся вписать источник и тип лицензии.
3. Прогнать `license-check`, если лицензия пака не очевидна.
4. Собрать игру и замерить: `npm run build -w @gamewingo/<slug>` →
   `node .claude/skills/perf-budget/scripts/perf-budget.mjs <slug>`.
5. Проверить на телефоне: webp понимают все актуальные WebView (iOS 14+, Android 5+),
   но именно эту игру всё равно надо открыть глазами по чеклисту `webview-qa`.

## 5. Когда растр вообще не нужен

Половина каталога рисуется кодом: значки — `makeGlyph` из `@gamewingo/game-ui`,
картинки пазла — примитивы через `Brush` в `games/jigsaw/src/game/painters.ts`.
Ноль байт, ноль лицензий, любой размер без потери чёткости. Прежде чем заводить
растровый пак, стоит спросить, не рисуется ли это фигурами.
