# Скилл: webview-qa

Финальный гейт перед деплоем игры в каталог. Проверять на реальных устройствах, не только в десктоп-браузере.

## 1. Вес и загрузка

- [ ] Прод-билд `npm run build -w @gamewingo/<slug>` — размер `dist/` < 5 МБ (цель < 2 МБ)
- [ ] Загрузка < 3 сек на 3G (throttling в DevTools как минимум)
- [ ] Спрайты сжаты, нет лишних ассетов в `public/`; атласы вместо россыпи PNG где уместно

## 2. Производительность

- [ ] Стабильные 60 fps на бюджетном Android (устройство ~$100)
- [ ] Нет утечек: при рестарте партии старые объекты/таймеры уничтожаются
- [ ] `bridge.destroy()` и очистка сцен при выходе

## 3. Мобильный UX

- [ ] Тач-управление работает (свайпы/тапы), не завязано на hover/клавиатуру
- [ ] Portrait по умолчанию; при landscape — корректный ресайз или заглушка
- [ ] Учтены safe-area (вырезы/нижняя панель), элементы не под системными барами
- [ ] Читаемые размеры кнопок/шрифтов на маленьком экране

## 4. WebView и офлайн

- [ ] Проверено в iOS WKWebView и Android WebView (а не только Chrome desktop)
- [ ] Мост выбирает правильный транспорт (iOS/Android/web-фолбэк)
- [ ] Поведение при потере сети: игра не виснет, ошибка `submitScore` обработана (ретрай/сообщение)
- [ ] `GAME_ERROR` шлётся при фатальной ошибке — приложение покажет фолбэк

## 5. Финтех и античит

- [ ] Баллы НЕ начисляются на клиенте — только `submitScore` на сервер
- [ ] Слаются `sessionId`, `durationMs`; сервер валидирует время сессии и max score
- [ ] UI-награда показывается только после `accepted` от сервера
- [ ] Нет реальных денег/выводов (App Store Guideline 4.7)

## 6. Локализация и бренд

- [ ] Все строки локализованы (RU/UZ), нет хардкода
- [ ] Палитра/лого применяются из `theme` (INIT) и/или брендбука
- [ ] Экран «Об игре» с атрибуцией, если требует лицензия ассета (CC-BY)

## 7. Юридическое

- [ ] Строка в `docs/LICENSES.md` заполнена (код + ассеты)
- [ ] Сохранены файлы LICENSE форкнутых шаблонов
- [ ] Удалены реклама и сторонняя аналитика из исходного шаблона
