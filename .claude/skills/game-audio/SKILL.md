# Скилл: game-audio

Звук в каталоге общий: восемь эффектов из пака Kenney (CC0), 27 КБ на игру, один слой
на всех — `packages/game-ui/src/audio.ts`. Игра не носит свой звук и не решает, как он
устроен; она только говорит, что произошло.

## 1. Как это собрано

```
packages/game-ui/audio/*.mp3      мастер-копия + LICENSE.txt (CC0)
packages/game-ui/src/audio.ts     слой: разблокировка, mute, загрузка, синтез-фолбэк
scripts/sync-audio.mjs            раскладывает пак по games/<slug>/public/audio/
```

Восемь имён и их смысл: `tap` (нажатие), `ok` (верный ход), `wrong` (ошибка),
`win` (уровень пройден), `lose` (партия проиграна), `coin` (начислен бонус),
`star` (получена звезда), `swipe` (сдвиг).

Четыре решения, которые уже приняты и которые не надо принимать заново:

- **mp3, а не AAC.** Единственный формат, который декодируют и WKWebView на iOS,
  и Android WebView, и любая сборка Chromium. На AAC открытые сборки Chromium падают
  с `EncodingError` — а это все headless-проверки и часть тестовых стендов.
- **Разблокировка по жесту.** iOS не даёт звук вне обработчика касания;
  `installAudioUnlock()` в `main.ts` вешает разовый слушатель на документ.
- **Общий выключатель.** Ключ `wingo:sound` в localStorage один на весь каталог:
  выключил в одной игре — тихо во всех.
- **Синтез как страховка.** Если файл не догрузился (3G, офлайн), играет
  осциллятор — тишина хуже приблизительного звука.

## 2. Подключить звук к новой игре

```ts
// src/main.ts
import { installAudioUnlock } from './game/ui';
installAudioUnlock();
```

```ts
// src/game/scenes/MainMenu.ts — под пилюлями выбора языка
makeSoundToggle(this, CX, y + 44, {
  on: t(this.locale, 'sound.on'),
  off: t(this.locale, 'sound.off'),
});
```

Ключи `sound.on` / `sound.off` — в `src/i18n/ru.json` и `uz.json`
(«Звук: вкл» / «Ovoz: yoqilgan»), и в список `REQUIRED` в `i18n.test.ts`.

```ts
// сцены игры
import { playSound } from '../ui';

playSound('ok');     // ход зачтён
playSound('wrong');  // ошибка
playSound('win');    // итог: победа
```

Звук нажатия кнопок добавлять **не нужно**: `makeButton`, `makeBackButton` и стрелка
в шапке уже играют `tap` сами. Дублирующий вызов даст двойной щелчок.

Файлы разложит `npm run audio:sync` (он же входит в `npm run build:all`).

## 3. Куда какой звук ставить

| Момент в игре | Звук | Где это уже сделано |
|---|---|---|
| Верный ход, пара, кусочек встал | `ok` | pairs, jigsaw, sorting, counting, soz |
| Ошибка, промах, отказ ввода | `wrong` | quiz, sudoku-kids, targets, soz |
| Сдвиг плиток, взмах | `swipe` | 2048, fifteen, flyer |
| Уровень пройден / забег кончился | `win` / `lose` | все 13 |
| Каждая звезда в итогах | `star` | все 13, с задержкой 160 мс между звёздами |
| Прилёт «+N» на чип баланса | `coin` | все 13 |

Правило: звук вешается на **событие правил игры**, а не на анимацию. Иначе он
рассинхронизируется при первом же изменении тайминга твина.

## 4. Свои файлы (музыка, особые эффекты)

1. Лицензия — через скилл `license-check`. Годятся CC0 (Kenney, OGA с пометкой CC0)
   и купленные паки. **CC-BY-NC и GPL — нельзя** (правило №4).
2. Конвертация в моно mp3:
   ```bash
   ffmpeg -i вход.ogg -ac 1 -ar 44100 -b:a 96k -c:a libmp3lame выход.mp3
   ```
   `ffmpeg` в среде разработки может отсутствовать — ставится `apt-get install -y ffmpeg`
   (сначала `apt-get update`). Конвертация разовая: в репозиторий едет готовый mp3.
3. Эффект короче 1.5 сек, музыкальный цикл — до 30 сек.
4. Бюджет: всё аудио одной игры ≤ 300 КБ.
5. Строка в `docs/LICENSES.md` — до коммита файлов.

## 5. Проверка

```bash
npm run check:audio            # все игры
npm run audio:sync -- --check  # пак разложен и не разъехался с мастером
```

`check:audio` ловит: несжатый формат, превышение бюджета, файл без строки в реестре
лицензий, отсутствие разблокировки по жесту, отсутствие выключателя. Код возврата 1 —
есть блокеры.

Отдельно: в headless-браузере звук не слышно, но проверяемо. Рабочий приём — подменить
`AudioContext.prototype.decodeAudioData` и `createBufferSource` счётчиками и убедиться,
что после первого жеста декодировалось 8 из 8, тап по кнопке запускает ровно один
источник, а в беззвучном режиме — ни одного.

## 6. Чего делать нельзя

- Играть звук до жеста пользователя — в iOS не сработает, в Android напугает.
- Забыть выключатель: WebView открыт поверх банковского приложения.
- Тянуть howler.js ради восьми эффектов — слой занимает ~4 КБ исходника без зависимостей.
- Класть `.wav` в `public/` — это несжатый звук, проверка его завернёт.
