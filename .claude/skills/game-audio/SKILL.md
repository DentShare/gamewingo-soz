# Скилл: game-audio

В каталоге звука не было ни в одной игре — и это не случайность: аудиофайлы съедают бюджет
(правило №7: билд < 2 МБ) и тянут за собой лицензии (правило №4). Поэтому базовый слой звука
здесь **синтезированный**: восемь эффектов на WebAudio, ноль байт в билде, ноль строк в
`docs/LICENSES.md`. Готовые аудиофайлы подключать можно, но только по разделу «Готовые файлы».

## 1. Подключить синтез (обычный путь)

Скопировать слой в игру:

```bash
cp .claude/skills/game-audio/assets/audio.ts games/<slug>/src/game/audio.ts
```

В `src/main.ts` — один раз, сразу после создания игры:

```ts
import { installAudioUnlock } from './game/audio';

installAudioUnlock();   // iOS WKWebView даёт звук только после жеста пользователя
```

В сценах — по событию:

```ts
import { playSound } from '../audio';

playSound('tap');    // нажатие кнопки
playSound('ok');     // верный ход, пара найдена, кусочек встал
playSound('wrong');  // ошибка
playSound('coin');   // начислен бонус
playSound('star');   // получена звезда
playSound('win');    // уровень пройден
playSound('lose');   // партия проиграна
playSound('swipe');  // свайп, сдвиг плиток
```

Переключатель в главном меню — чипом дизайн-системы, без эмодзи (правило №5):

```ts
import { makeChip } from '../ui';
import { isMuted, setMuted } from '../audio';

const sound = makeChip(this, CX, 660, t(this.locale, isMuted() ? 'sound.off' : 'sound.on'), 120);
sound.container.setInteractive(
  new Phaser.Geom.Rectangle(-60, -16, 120, 32), Phaser.Geom.Rectangle.Contains,
);
sound.container.on('pointerdown', () => {
  setMuted(!isMuted());
  sound.setText(t(this.locale, isMuted() ? 'sound.off' : 'sound.on'));
  if (!isMuted()) playSound('tap');
});
```

Ключи `sound.on` / `sound.off` добавить в `src/i18n/ru.json` и `uz.json`
(«Звук: вкл» / «Звук: выкл», «Ovoz: yoqilgan» / «Ovoz: o'chirilgan») и проверить
скиллом `content-pack`.

## 2. Что уже решено в слое

- **Выключено по умолчанию не бывает**: состояние живёт в `localStorage` под ключом
  `wingo:sound`, общий для всего каталога — выключил в одной игре, тихо во всех.
- **iOS WebView**: `AudioContext` создаётся лениво, при первом `pointerdown`/`touchend`;
  без этого iOS молчит и не сообщает об ошибке.
- **Нет утечек**: контекст один на страницу, осцилляторы сами себя выключают по
  `onended`; `stopAudio()` нужен только при выгрузке игры.
- **Безопасно в тестах и SSR**: без `window.AudioContext` все функции — пустышки,
  вызов `playSound` в vitest ничего не ломает.
- **Громкость**: мастер-гейн 0.18 — звук слышен в тишине и не бьёт по ушам в наушниках,
  когда WebView открыт поверх приложения.

## 3. Готовые файлы (когда синтеза мало)

Фоновая музыка и «живые» эффекты синтезом не делаются. Тогда:

1. Проверить лицензию скиллом `license-check` — **никаких CC-BY-NC, GPL/AGPL**.
   Годятся CC0 (Kenney, Freesound CC0) и купленные паки с коммерческой лицензией.
2. Формат: `.m4a`/`.aac` или `.ogg` + `.m4a` фолбэком (iOS не играет ogg).
   `.wav` в билде — ошибка, это несжатый звук.
3. Моно, 64–96 kbps, эффект короче 1.5 сек. Музыка — цикл до 30 сек, не длиннее.
4. Бюджет: всё аудио одной игры ≤ 300 КБ.
5. Строка в `docs/LICENSES.md` на каждый пак — до того, как файлы легли в `public/`.

Проверка:

```bash
node .claude/skills/game-audio/scripts/check-audio.mjs          # все игры
node .claude/skills/game-audio/scripts/check-audio.mjs quiz     # одна игра
node .claude/skills/game-audio/scripts/check-audio.mjs --json   # для CI
```

Скрипт находит аудиофайлы в играх, считает вес против бюджета, ругается на `.wav`
и на файлы без строки в реестре лицензий, а для игр со звуком проверяет, что
разблокировка (`installAudioUnlock`) и переключатель (`setMuted`) на месте.
Код возврата 1 — есть блокеры.

## 4. Чего делать нельзя

- Играть звук до жеста пользователя — в iOS это не сработает, а в Android напугает.
- Забыть переключатель: WebView открыт поверх банковского приложения, беззвучный
  режим обязателен.
- Тянуть howler.js или другую библиотеку ради восьми «биппов» — слой ниже занимает
  ~3 КБ исходника и ноль зависимостей.
