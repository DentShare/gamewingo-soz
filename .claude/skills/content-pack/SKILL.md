# Скилл: content-pack

Контент в каталоге живёт по двум правилам: **всё на двух языках** (RU/UZ) и **ни одной
строки текста в сценах**. Скилл держит оба правила и даёт шаблоны, чтобы добавление
контента не превращалось в археологию по чужим файлам.

## 1. Проверка (запускать всегда)

```bash
node .claude/skills/content-pack/scripts/check-content.mjs          # все игры
node .claude/skills/content-pack/scripts/check-content.mjs quiz     # одна игра
node .claude/skills/content-pack/scripts/check-content.mjs --json   # для CI
```

Блокеры (код возврата 1):

- ключ есть в `ru.json`, но нет в `uz.json` — или наоборот;
- пустое значение;
- разный набор подстановок `{n}` в ru и uz — строка сломается при подстановке;
- ключ объявлен в JSON дважды (`JSON.parse` молча оставляет последний);
- `t(locale, 'ключ')` без такого ключа в словаре;
- строковый литерал с кириллицей вне словарей и контент-паков — хардкод текста.

Предупреждения: ключ никем не используется; узбекская строка дословно равна русской.

Исключения из проверки на хардкод: названия языков (`Русский`, `Oʻzbekcha` — эндонимы
не переводятся) и строка с пометкой `// i18n-ignore` в конце.

## 2. Новая тема викторины

Файл `games/quiz/src/content/<topic>.ts` — по образцу `money.ts`:

```ts
import { q, type Question } from './types';

export const SPORT: Question[] = [
  q('sport-marathon', 'sport',
    { ru: 'Какова длина марафона?', uz: 'Marafon uzunligi qancha?' },
    [
      // Первый вариант — всегда верный: в партии список перемешивается.
      { ru: '42 км 195 м', uz: '42 km 195 m' },
      { ru: '30 км ровно', uz: 'Roppa-rosa 30 km' },
      { ru: '50 км', uz: '50 km' },
    ],
    { ru: 'Дистанцию округлили до 42 195 м в 1908 году — ради удобства королевской ложи.',
      uz: 'Masofa 1908-yilda 42 195 m ga yaxlitlangan — qirol locasi uchun qulay boʻlsin deb.' }),
];
```

Дальше:

1. `src/content/types.ts` — добавить `'sport'` в `TopicId` и в `TOPICS`.
2. `src/content/index.ts` — импорт и строку в `BY_TOPIC`.
3. `src/i18n/ru.json` и `uz.json` — ключ `topic.sport` (сцена берёт название темы
   как `t(loc, \`topic.${id}\`)`), и обновить `menu.topics`.
4. Проверить: `npm test -w @gamewingo/quiz` — тесты держат уникальность id,
   заполненность обоих языков и минимум три варианта.

Требования к вопросам:

- **10 вопросов на тему** — меньше видно повторы, лестница берёт вопросы из общего банка;
- факт важнее вопроса: он и есть причина играть, одно предложение, проверяемое;
- никаких обещаний доходности и реальных денег в теме «Деньги» (правило №3);
- id устойчивый: порядок в файле менять можно, id — нельзя, по нему считается,
  какие вопросы игрок уже видел.

## 3. Новая картинка и история пазла

`games/jigsaw/src/core/pictures.ts`:

```ts
{
  id: 'night-garden',
  title: { ru: 'Ночной сад', uz: 'Tungi bogʻ' },
  story: {
    ru: 'Когда все засыпают, сад начинает шуметь листвой…',
    uz: 'Hamma uxlaganda, bogʻ barglari shitirlay boshlaydi…',
  },
  // src: 'pictures/night-garden.webp',  ← когда придёт готовая иллюстрация
},
```

Пока `src` не задан, картинку рисует векторная сцена в `src/game/painters.ts` —
там нужен ключ с тем же `id`. Готовые файлы проводить через скилл `asset-pipeline`
(336 × 336, webp) и записывать строкой в `docs/LICENSES.md`.

История — 2–3 предложения, детская, без назидания и страха, про то, что на картинке.
Читается вслух родителем; длинные придаточные не нужны.

## 4. Слова «Сўз»

`games/soz/src/core/dictionary.ts` — слова из пяти букв. Проверять: только буквы
узбекского алфавита, без имён собственных и заимствований, которых ребёнок не знает.

Слово дня — это `answers[hash(dayId) % answers.length]`. Значит **любая правка списка**
(и порядок, и длина) меняет сегодняшнее слово у всех игроков сразу. Пополнять словарь
можно, но осознанно и лучше не в середине дня.

## 5. Узбекский

- Латиница, современная орфография: `oʻ` и `gʻ` — с модификатором `ʻ` (U+02BB), не с апострофом.
- Кавычки-ёлочки в русском («…»), в узбекском — “…”.
- Не переводить дословно: узбекская строка короче русской на 10–20 %, кнопки узкие.
- Если перевода пока нет — **не** копировать русский текст: скрипт это поймает
  предупреждением, а игрок увидит русский в узбекском интерфейсе.
