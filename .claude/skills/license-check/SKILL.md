# Скилл: license-check

Гейт перед использованием чужого кода/ассетов. Итог — строка в `docs/LICENSES.md`.

## Чеклист выбора шаблона (перед форком/покупкой)

- [ ] Лицензия разрешает закрытый коммерческий продукт (см. таблицу ниже)
- [ ] Движок Phaser 3/4 или чистый JS/Canvas (не Unity, не Flash-порт)
- [ ] Вес билда < 5 МБ (лучше < 2 МБ)
- [ ] Работает в мобильном браузере: тач, portrait
- [ ] Код читаемый (TS или аккуратный ES6+), не минифицированные «исходники»
- [ ] Нет жёстко вшитой рекламы/аналитики
- [ ] Ассеты отделены от логики (легко заменить на брендированные)
- [ ] Репозиторий/товар живой (обновления за 1–2 года)

## Матрица лицензий

| Лицензия | Можно в закрытый коммерческий | Условие |
|---|---|---|
| MIT / Apache 2.0 / BSD | ✅ | сохранить LICENSE + копирайт в коде |
| CC0 | ✅ | без условий |
| CC-BY | ✅ | указать автора (экран «Об игре») |
| CC-BY-NC | ❌ | запрет коммерции |
| GPL / AGPL | ❌ | требует раскрыть исходники — исключаем |
| CodeCanyon Regular | ✅ (1 продукт) | продукт бесплатен для пользователей |
| CodeCanyon Extended | ✅ (1 продукт) | если доступ к продукту платный |

> Для приложения банка обычно достаточно **CodeCanyon Regular** (пользователи не платят за игры) —
> но зафиксировать письменно в реестре.

## Шаги

1. Определить лицензию источника (файл LICENSE, страница товара, README).
2. Прогнать чеклист выше. Любой ❌ по лицензии → **не использовать**, предложить альтернативу.
3. Внести строку в `docs/LICENSES.md`: источник (URL) → лицензия → условия к исполнению → дата → кто проверил.
4. Если лицензия требует атрибуцию (CC-BY) — отметить это в SPEC.md игры (экран «Об игре»).
5. Сохранить оригинальный файл LICENSE в папке игры.

## Красные флаги

- Нет явной лицензии в репозитории → считать «все права защищены», не использовать.
- Смешанные ассеты (часть CC0, часть неизвестно) на OpenGameArt → проверять каждый ассет отдельно.
- «Free for personal use» → это НЕ коммерческая лицензия.
