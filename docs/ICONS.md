# Иконки игр

Одна иконка на игру: она же в карточке каталога и в меню самой игры.

```
scripts/gen-icons.mjs          ← генератор (изометрия, палитра, вписывание в кадр)
hub/icons/<slug>.svg           ← для каталога (<img> 82×82)
games/<slug>/public/icon.svg   ← та же картинка внутри игры (Phaser грузит как текстуру)
```

Пересобрать после правки генератора:

```bash
node scripts/gen-icons.mjs
```

Оба файла пишутся одной командой — расхождение между каталогом и игрой невозможно.

## Стиль

Изометрия «глянцевый пластик»: три грани на объём (верх светлее, правая темнее),
мягкая контактная тень, блик на верхних гранях. Палитра строгая:

| Материал | Значения |
|---|---|
| бирюза | `#2FA7A0` → `#6FCFC7` |
| оранжевый | `#FF7A00` → `#FFA94D` |
| белый | `#D9DEE1` → `#FFFFFF`, тень `#B9C3C7`, пустая ячейка `#E3E8EA` |

Других цветов в наборе нет.

## Иконка обязана объяснять игру

Не абстрактная композиция, а сцена из механики: цифры, буквы и знаки лежат на гранях.
Что показывает каждая: `С Л О` со статусами букв (5 букв), две одинаковые карточки и `?`
(Найди пару), плитки `1 2 3` и пустой слот со стрелкой (Пятнашки), `2 → 4 → 8` (2048),
доска с `1` и `2` (Мини-судоку), слои со стрелкой роста (Башня), проём и кораблик
(Полёт), мишень с прицелом (Меткий глаз), тело с головой и яблоко (Змейка), две ячейки
с разными фигурами (Сортировка), три предмета и ответ `3` (Счёт).

## Вписывание в кадр

Генератор считает габариты композиции и масштабирует её в **84 % холста** с
центрированием — минимум 8 % полей с каждой стороны, обрезка краем невозможна.
Габариты учитывают и выносные элементы (например, след за корабликом), поэтому
новая композиция не требует ручной подгонки координат.

## Как добавить иконку новой игре

1. Дописать композицию в `ICONS` в `scripts/gen-icons.mjs` — примитивы `box`, `disc`,
   `sphere`, `extrude`, `plate`, `recess`, наклейки `label` / `shape` / `chevron`.
2. `node scripts/gen-icons.mjs` — файлы появятся сами.
3. Вписать slug в `FILE_ICONS` в `hub/index.html`.
4. В `Boot` игры вызвать `loadGameIcon(this)` в `preload()`, в меню — `makeGameIcon(...)`.

Пока slug'а нет в `FILE_ICONS`, каталог рисует запасной плоский значок из
`packages/game-ui/src/glyphs.ts` — хаб не ломается от отсутствия файла.

## Если понадобятся растровые иконки

3D-рендеры (Blender / AI) подключаются вместо SVG без правок вёрстки: положить
`hub/icons/<slug>.png`, поменять расширение в `iconHtml()`. Требования к файлам:
прозрачный фон, квадрат 1:1, 512 px и больше, одинаковые поля во всех иконках набора.
Промты для генерации — `docs/ICON-PROMPTS.md`.

## Лицензии

Набор нарисован генератором внутри репозитория — сторонних прав нет, строка в
`docs/LICENSES.md`. Для покупных или AI-иконок лицензия фиксируется отдельно.
