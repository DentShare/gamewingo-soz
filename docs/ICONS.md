# Иконки игр в хабе

Иконка игры — квадрат **82×82 CSS-пикселя** в тайле хаба (`background #FFEBE2`, радиус 12).
В макете это 3D-рендеры, положенные в Figma картинками (PNG), поэтому в проект они
переносятся растром, а не вектором.

## Где лежат

```
hub/icons/<slug>.webp     ← 246×246 (@3x от 82), прозрачный фон
```

`<slug>` — идентификатор игры из `games/manifest.json`:
`soz, pairs, fifteen, 2048, sudoku-kids, stack, flyer, targets, snake, sorting, counting`.

## Как подключить иконку (2 шага)

1. Положить файл в `hub/icons/<slug>.webp`.
2. Вписать slug в `RASTER_ICONS` в `hub/index.html`.

Пока slug'а нет в этом наборе, рисуется векторный запасной вариант из `ICONS` —
хаб не ломается от отсутствия файла и не делает лишних запросов.

## Требования к экспорту из Figma

| Параметр | Значение | Почему |
|---|---|---|
| Фон | **прозрачный** (альфа), не белый | тайл в хабе цветной `#FFEBE2` — белый квадрат будет виден |
| Пропорции | строго 1:1 | иначе иконка «поедет» в тайле |
| Размер | 512×512 или 1024×1024 PNG | ужимаем на нашей стороне, апскейл невозможен |
| Поля | одинаковые во всех иконках набора | иначе в списке иконки визуально «прыгают» по размеру |
| Формат исходника | PNG-24 с альфой | JPEG теряет прозрачность |
| Имя файла | `<slug>.png` | чтобы не сопоставлять вручную |

Экспорт в Figma: выделить иконку → Export → PNG → 4x (при кадре 256) → Export.

## Что делаем с файлами на нашей стороне

Приводим к `246×246` и конвертируем в WebP (вес ~15–25 КБ против ~60–120 КБ у PNG).
WebP понимают все WebView, где работает каталог (iOS 14+, современный Android).
Оригиналы PNG в репозиторий не кладём — они лежат у дизайнера в Figma.

## Стиль набора (для новых игр)

Чтобы двенадцатая игра не выбивалась, новая иконка повторяет параметры набора:

- изометрия, вид сверху-справа, один и тот же угол для всех иконок;
- «пластилиновая» пластика: скруглённые рёбра, мягкий глянец, без обводок;
- корпус/подложка — белый с холодной серой тенью;
- акценты — оранжевый и приглушённый зелёный из палитры каталога;
- мягкая тень под объектом, источник света сверху-слева;
- объект занимает ~85 % квадрата, остальное — поля.

Лучший способ удержать стиль — рисовать новую иконку из того же исходника
(сцена/шаблон 3D или компонент в Figma), а не «на глаз».

## Лицензии

Каждая иконка — строка в `docs/LICENSES.md`: источник (свой рендер / пак / AI),
лицензия, условия. Без записи ассет в продукт не идёт.
