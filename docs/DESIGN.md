# Дизайн-система каталога

Единая визуальная система хаба и всех игр. Значения взяты из макета WinGo (Figma,
экран «Games») — это источник правды, менять их здесь и только здесь.

Реализация: `packages/game-ui` (для игр на Phaser) и `<style>` в `hub/index.html`
(для хаба на HTML). Обе стороны обязаны совпадать по значениям ниже.

## Цвета

| Токен | Значение | Где |
|---|---|---|
| `primary` | `#F76624` | кнопки, активные состояния |
| `primaryPressed` | `#DC5314` | нажатая кнопка |
| `accent` | `#4E9B90` | второй акцент (декор, игровые поля) |
| `success` | `#3AA657` | «верно»: угаданная буква в «5 буквах», подтверждение |
| `successBg` | `#E3F3E7` | мягкая подложка «сошлось» (сумма строки в «Суммах»); пара к `dangerBg` |
| `ink` | `#1A1A1A` | заголовки и основной текст |
| `muted` | `#8E97A7` | подписи, второстепенный текст |
| `bg` | `#F9F9F9` | фон экрана |
| `surface` | `#FFFFFF` | карточки, панели, светлые кнопки |
| `tint` | `#FFEBE2` | подложка иконок, мягкие блоки |
| `chipBg` / `chipInk` | `#FFDDBF` / `#FA7700` | чипы (метки, счёт, таймер) |
| `divider` | `#D9D9D9` при alpha 0.4 | разделители |
| `topBar` | градиент 270°: `#FF7700` → `#FD7B03` (49.52%) → `#FF5001` | шапка |

Градиент шапки в CSS идёт справа налево (`270deg`), в канвасе это слева `#FF5001`,
справа `#FF7700`.

## Радиусы и отступы

- радиус карточек и кнопок — **12**, чипов — **8**;
- поля экрана — **20**, внутренние поля карточки — **12**;
- шаг сетки — **4 / 8 / 12 / 20**.

## Типографика

Системный шрифт платформы: `system-ui, -apple-system, 'SF Pro Text', Roboto, sans-serif`.
Макет свёрстан на SF Pro, поэтому на iOS совпадает буквально, на Android — Roboto.
Веб-шрифты в каталоге больше не поставляются.

| Роль | Размер / интерлиньяж | Начертание |
|---|---|---|
| `display` (титул игры в меню) | 34 | 700 |
| `title` (заголовок в шапке) | 20 / 25, трекинг −0.45 | 590 |
| `headline` (заголовок секции) | 17 / 22, трекинг −0.43 | 590 |
| `body` (кнопки, названия) | 15 / 20, трекинг −0.23 | 590 |
| `caption` (подписи, чипы) | 12 / 16 | 400 / 700 в чипе |

## Компоненты

**Шапка.** Высота 56 в игре (в хабе — safe-area + 46). Градиент `topBar`, слева
стрелка 32×32 белым, по центру заголовок `title`. Тап по стрелке — выход в каталог
(`GAME_EXIT` через мост, в вебе — переход на хаб).

**Кнопка.** Плоская, радиус 12, без объёмного бортика.
- `primary`: заливка `primary`, текст белый;
- `secondary`: заливка `surface`, текст `ink`, обводка 1px `divider`;
- размеры: `md` — высота 40 (по умолчанию), `lg` — 48 (главный CTA в меню);
- нажатие: заливка темнеет до `primaryPressed` (у светлой — до `tint`).

**Карточка.** `surface`, радиус 12, без обводки и тени в канвасе (в хабе — мягкая тень).

**Чип.** `chipBg`, радиус 8, текст `chipInk` 12/700, поля 8×4. Используется для
метрик в HUD (счёт, время, ходы) и меток.

**Тост.** Тёмная плашка `ink` с белым текстом 15, радиус 12, автоскрытие.

**Переключатель звука.** Чип с подписью «Звук: вкл / выкл» (`makeSoundToggle`).
Живёт в паузе партии, а не в меню игры. Состояние общее для каталога.

**Шапка партии** (`makeGameHeader`). Та же шапка 56, но справа — белые
полупрозрачные чипы метрик: ходы «11 / 20», таймер «0:09», счёт. Ширина чипа —
по самому длинному тексту (`widest`), чтобы растущее число не наезжало на
соседа. Последние секунды таймера — `warn`: белая плашка, красный текст. Отклик
на удачный ход — `pulseChip`. Метрики только в шапке, дублей на поле нет.

**Пауза** (`openPauseSheet`). Стрелка в шапке партии и системный «назад»
открывают шит снизу, а не выкидывают из партии. На шите «Пауза», строка
состояния («Таймер остановлен · ходы 11 / 20 · осталось 0:09»), «Продолжить»,
«Начать заново», «Выйти» с честной подписью и ряд чипов «Звук» / «Как играть».
Подписи по `kind`:
- `level` — «Выйти — прогресс уровня не сохранится» (красная);
- `run` — забег аркады: «Выйти — забег не засчитается» (красная);
- `saved` — партия сохраняется сама (2048, слово дня): «Выйти — партия
  сохранится», обычная кнопка.

Короткий тап по затемнению — «Продолжить»; свайп паузу не закрывает. Пока шит
открыт, мир стоит: таймер, ядро, твины, `time.paused` у аркад. Событие `RESUME`
от приложения при открытой паузе часы не запускает — продолжает игрок.

**Экран итогов** (`makeLadderResult`, `makeArcadeResult` в `results.ts`). Одна валюта
на экране — бонусы; очков у лестниц нет, лидерборд только у слова дня.
- Лестница: «Уровень 3 · Глава 1» (15 muted) → заголовок 30/700 → звёзды 52 →
  карточка «почти» («До третьей звезды — 1 ход», детали 12 muted, «Ещё раз» 36 справа;
  только при < 3 звёзд) → карточка бонусов → primary 48 «Уровень 4 · новое: 6 пар» →
  «В меню» 40.
- Аркада: «Забег · 1:12» → главная цифра («Длина 17», «Новый рекорд · 23») → чипы
  «960 очков · рекорд 20» → карточка «Почти! Испытание 4» (рамка primary 2, бар 8,
  «В этом забеге: 9 · не хватило 3», чип «+26») или закрытое испытание (зелёная) →
  «Следом» — два испытания с прогрессом → бонусы → «Ещё забег» / «В меню».
- Карточка бонусов: строки начислений («Первое прохождение уровня 3 +24»), одно
  незакрытое задание дня приглушённо «2/3 +15», разделитель, «Начислено +24» с монетой.
  Кнопки прижаты к низу вёрстки, если колонка короче.

**Обучение в один шаг** (`runFirstMoveTutorial` в `tutorial.ts`). Учим действием, а
не карточками: поле видно, цель первого хода обведена (primary 3 px, пульс 1,4 с),
остальное приглушено; внизу тёмная полоса (ink, радиус 12, текст 15 белый) с одной
фразой и кнопкой «Пропустить» 40 px. Тап по цели — настоящий ход, обучение
заканчивается после первого удачного (`done()`). Метрики шапки спрятаны до него
(`setChipsVisible`), таймер стоит; строка `note` над полосой — «Таймер и ходы
включатся после первой пары». Опции: `shape: 'circle'` (мишень), `veilAlpha`
(аркада в движении — мягче), `barTop` (когда внизу то, что надо нажать).
«Как играть» в паузе запускает то же обучение.

**Правило в момент события** (`showRuleOnce`). Промах, лимит, ошибка — не карточкой
заранее, а тёмной строкой под шапкой, когда это впервые случилось, один раз на
устройство (`wingo:rules`). 2 с, длинная строка — дольше; `y` — если под шапкой
она закроет то, что объясняет.

**Детский режим** (`kids.ts`, флаг `kidsMode` в `games/manifest.json`, `setKidsMode(true)`
в `main.ts` игры). Игрок 3–6 лет не читает:
- меню — иконка 120, дорожка из пяти кружков (пройденный 56 зелёный со звёздами,
  текущий 72 primary с треугольником и пульсом, будущий — контуром, **без замков**:
  тап — покачивание), три дорожки = три главы, свайп; режим картинкой (цвета или
  формы); одна кнопка «играть» 88 с тенью primaryPressed 6 px и пульсом;
- шапка — слева «Родителям»: меню (вернуться, звук, выход в каталог) открывается
  только удержанием 2 с, кольцо прогресса на чипе; справа иконка звука; стрелки нет,
  системный «назад» в меню ничего не делает;
- итог — три звезды крупно, феникс (радуется или грустит), одна кнопка «дальше»;
  без очков, лидерборда и текста;
- обучение — только подсветка, без фразы и «Пропустить»; строки правил молчат.
  Озвучка подсказок появится вместе с файлами RU/UZ от контента.

**«Призрак» рекорда** (`makeRecordGhost`). Шкала 3 px под шапкой забега: заливка —
текущий забег, золотая метка — личный рекорд; обогнал — заливка золотая.

**Системный «назад»** (`setBackHandler`). Цепочка у всех игр одна:
партия → пауза → меню → каталог. С итогов — в меню.

## Звук

Часть дизайн-системы наравне с цветом: восемь эффектов, один пак на все игры
(`packages/game-ui/audio`, Kenney, CC0, 27 КБ). Пак зашит в бандл base64 —
отдельных запросов за звуком нет, работает офлайн. Правила — в скилле `game-audio`.

| Событие | Звук | Кто играет |
|---|---|---|
| Нажатие кнопки | `tap` | сам виджет `makeButton` / `makeBackButton` / шапка |
| Верный ход | `ok` | сцена игры |
| Ошибка, промах | `wrong` | сцена игры |
| Сдвиг, свайп, взмах | `swipe` | сцена игры |
| Итог: победа / поражение | `win` / `lose` | экран итогов |
| Звезда в итогах | `star` | экран итогов, по одной с шагом 160 мс |
| Прилёт «+N» на чип баланса | `coin` | экран итогов |

Два правила, которые легко нарушить: звук вешается на событие правил игры,
а не на анимацию; в партии и на экране итогов не звучит один и тот же эффект
подряд (удар в партии — `wrong`, вердикт — `lose`).

## Маскот

Феникс — птица финтеха, поэтому он же маскот каталога. Рисуется примитивами
(`packages/game-ui/src/phoenix.ts`), а не картинкой: любой размер без потери
чёткости, ноль байт в билде, ноль строк в реестре лицензий.

- **Где живёт:** полоса приветствия в хабе (SVG той же геометрии) и правый нижний
  угол экрана итогов во всех четырнадцати играх.
- **Что умеет (v2):** настроения `idle`, `happy`, `sad`, `fly`, `curious` через
  `setMood()`; `celebrate()` и `sink()` — короткие пути к `happy` и `sad`, `blink()` —
  моргнуть. В покое семь движений с разными периодами: дыхание, хвост, хохолок,
  кивок, микровзмах крыла, взгляд, моргание. Угли от хвоста — только при `size ≥ 84`.
- **Уменьшить движение:** при `prefers-reduced-motion` остаются дыхание, моргание
  и поза «поник» — она несёт смысл, а не украшает (`motionAllowed()` в `motion.ts`).
- **Размеры:** 84 на экране итогов, 52 в хабе, до 120 в меню. `size` — рост птицы;
  хвост и хохолок выходят за условный квадрат примерно на 15 % — закладывайте отступ.
- **Цвета:** `primary`, `primarySoft`, `primaryPressed`, `gold` и девять оттенков
  перьев `PHOENIX_SHADES` из `tokens.ts`. Оттенки перьев — только для маскота,
  в интерфейсе ими не красят.

## Движение

Единый набор кривых и длительностей — `packages/game-ui/src/motion.ts`.

| Что происходит | Кривая | Длительность |
|---|---|---|
| Появление (карточки, звёзды, кнопки) | `EASE.pop` | 280 мс |
| Уход со сцены | `EASE.in` | 420 мс |
| Отклик на тап | `EASE.settle` | 120 мс |
| Бесконечное покачивание | `EASE.smooth` | 1800 мс |

Приёмы: `pop` — появление из нуля с перелётом; `squash` — приседание при
приземлении (без него объект выглядит невесомым); `sparkle` — искры на
партиклах с текстурой из рантайма; `pulse` — «сюда смотреть».

Правило про искры: они ставятся туда, где визуальной реакции **не было**.
На экране итогов уже работает конфетти — добавлять туда искры значит удваивать
шум по одному поводу.

## Правила

1. Никаких локальных хексов в сценах — только токены из `@gamewingo/game-ui`.
2. Игровое поле (плитки, фишки, персонажи) может иметь свои цвета, но они
   выводятся из `primary` / `accent` / `tint`, а не выбираются заново.
3. Новый экран сначала собирается из компонентов выше; новый компонент —
   сначала строка в этом файле, потом код.
