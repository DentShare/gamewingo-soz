# Архитектура каталога

## Общая схема

```
Финтех-приложение (iOS / Android)
        │  WebView (WKWebView / Android WebView)
        ▼
   HTML5-игра (Phaser 4, статический билд на Vercel)
        │  @gamewingo/game-bridge  (postMessage / JS-мост)
        ├── события игры → приложение (GAME_OVER, REWARD_CLAIM, ...)
        └── события приложения → игра (INIT с токеном/темой, PAUSE/RESUME)
        │
        ▼  fetch с Bearer-токеном
   Бэкенд FastAPI + Supabase
        ├── серверная валидация результата (антифрод)
        ├── начисление баллов / кэшбэка
        └── лидерборды, стрики (RLS для мультитенантности)
```

## Правила, которые нельзя нарушать

1. **Игра не начисляет баллы.** Она отправляет `score` + `durationMs` + `sessionId`. Сервер решает.
2. **Антифрод — на сервере:** лимит времени сессии, максимально возможный score, частота наград.
3. **Никаких реальных денег** внутри игр (App Store Guideline 4.7) — только виртуальные баллы/кэшбэк.
4. **Один движок на весь каталог — Phaser 4.** Один мост, один пайплайн, один набор навыков.
5. **Новые игры добавляются без релиза приложения** — через манифест каталога и деплой на Vercel.

## Поток событий (happy path)

```
Игра                         Приложение                    Бэкенд
 │  GAME_READY ───────────────▶ │
 │  ◀─────────── INIT(token,     │
 │              locale, theme,   │
 │              sessionId)       │
 │  GAME_START ───────────────▶ │  (старт таймера сессии на сервере)
 │      ... играем ...           │
 │  GAME_OVER(score,dur) ─────▶ │
 │  submitScore() ──────────────┼────────────────────────▶ валидация
 │  ◀───────────────────────────┼──── {accepted, pointsAwarded}
 │  REWARD_CLAIM ─────────────▶ │ ───────────────────────▶ проверка
 │  ◀─────────── REWARD_RESULT   │
```

## Стек (из внутренней инструкции)

| Слой | Технология |
|---|---|
| Движок | Phaser 4 (MIT) |
| Язык / сборка | TypeScript + Vite |
| Хостинг игр | Vercel (статический билд) |
| Бэкенд | FastAPI + Supabase |
| Связь | WebView + JS-мост (postMessage) |

## Референс-репозитории (лежат в корне GameWingo, не часть монорепо)

- `template-vite-ts-main` — официальный стартер Phaser (база для новых игр)
- `examples-master` — сотни мини-примеров механик Phaser
- `Enclave-Phaser-Template-gh-pages` — мобильный каркас (меню, прелоадер, PWA)
- `phaser3-rex-notes-master` — плагины/рецепты (UI, жесты, борды)
- `howler.js-master` — звук
- `canvas-confetti-master` — эффекты (награды, победа)
- `games-master` — примеры готовых игр
