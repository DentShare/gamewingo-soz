# Дизайн: игра «soz» (Wordle-механика для RU / UZ-латиница)

- **Дата:** 2026-07-24
- **slug / gameId:** `soz`
- **Статус:** согласован в брейншторме, готов к плану реализации
- **Связанные документы:** [`games/soz/SPEC.md`](../../../games/soz/SPEC.md), [`docs/ARCHITECTURE.md`](../../ARCHITECTURE.md), [`docs/LICENSES.md`](../../LICENSES.md)

## 1. Цель и контекст

Казуальная игра-угадайка слов (механика Wordle) для каталога GameWingo, встраиваемая в WebView
финтех-приложения. Игрок угадывает слово из 5 «букв-юнитов» за 6 попыток. Привязка к программе
лояльности: решённое слово дня → баллы (начисляет сервер). Две целевые аудитории: русскоязычная
(кириллица) и узбекоязычная (**латиница**, официальный script Узбекистана).

**Публичное название:** «5 harf» (UZ) / «5 букв» (RU). Слово «Wordle» — товарный знак NYT, в продукте
не используется; в документации — только как обозначение механики.

## 2. Ключевые решения (из брейншторма)

| Вопрос | Решение |
|---|---|
| Формат | Классика 5 юнитов × 6 попыток |
| UZ-алфавит | **Латиница** (oʻzbek lotin), диграфы `oʻ gʻ sh ch ng` = отдельные буквы |
| Режимы | `daily` (с наградой) + `practice` (без начисления) |
| Экономика | score-формула + серверный антифрод; суммы решает бэкенд |
| Словари | MVP-курасет (~100–200 слов/язык), растим позже |

## 3. Архитектура

### 3.1. Слои

```
games/soz/
├── src/
│   ├── core/           ← чистая логика, БЕЗ Phaser (юнит-тестируется)
│   │   ├── tokenizer.ts    диграф-осознанный разбор слова на юниты
│   │   ├── evaluate.ts     вычисление статусов юнитов (correct/present/absent)
│   │   ├── dailyWord.ts    детерминированный выбор слова дня по dayId
│   │   ├── dictionary.ts   загрузка/валидация словарей, проверка «слово существует»
│   │   └── gameState.ts    состояние партии (ряды, попытки, статус, режим)
│   ├── game/           ← Phaser 4: сцены и рендер
│   │   ├── scenes/Boot.ts      инициализация, мост, INIT
│   │   ├── scenes/Menu.ts      выбор режима / языка, сплэш
│   │   ├── scenes/Game.ts      сетка + клавиатура + ввод
│   │   └── scenes/Result.ts    итог, стрик, лидерборд, «Забрать награду», шэринг
│   ├── bridge/         ← обёртка над @gamewingo/game-bridge
│   ├── i18n/           ← ru.json, uz.json (+ en.json опц.)
│   └── data/           ← answers.<loc>.json, allowed.<loc>.json
└── SPEC.md
```

**Принцип:** вся игровая логика живёт в `core/` как чистые функции/классы без зависимости от Phaser —
это делает её тестируемой и переносимой. `game/` только рендерит состояние и передаёт ввод в `core/`.

**Схема словарей (`src/data/`):** каждый файл — JSON-массив строк в нормальной форме (нижний регистр,
`ʻ` = U+02BB, для `ru` без `ё`), каждое слово токенизируется ровно в 5 юнитов.
- `answers.<loc>.json` — курасет ответов (из них слово дня / practice).
- `allowed.<loc>.json` — дополнительный список валидных догадок, **дизъюнктный** с answers.
- `dictionary.has(w) = answersSet.has(w) || allowedSet.has(w)` — при загрузке оба массива
  разворачиваются в `Set` для O(1). «Слово существует» = есть в объединении.

### 3.2. Диграф-движок

- `type Unit = string` — одна «буква» (для `ru` = символ; для `uz` = символ или диграф).
- `tokenizeWord(word: string, locale: Locale): Unit[]`
  - `uz`: слева направо, на каждом шаге проверяет, начинается ли остаток с одного из `oʻ, gʻ, sh, ch, ng` → если да, откусывает диграф как один юнит; иначе — один символ.
  - `ru`: `Array.from(word)` (посимвольно).
- Нормализация ввода перед токенизацией: `'`, `’`, `ʼ`, `` ` `` → `ʻ` (U+02BB); нижний регистр.
- `evaluate(guessUnits, answerUnits): Status[]` — классический Wordle-алгоритм с двухпроходным
  учётом кратности (сначала `correct` на месте, потом `present` из оставшегося пула), но оперирует
  **юнитами**.
- Валидность слова: `tokenizeWord(w).length === 5 && dictionary.has(w)`.

### 3.3. Слово дня (пин: клиент и сервер считают идентично)

- **dayId:** `dayId = Math.floor((Date.now() + 5*3600*1000) / 86400000)` — целые дни по Asia/Tashkent
  (UTC+5, DST нет с 1992). Сервер обязан использовать ту же формулу.
- **Индекс:** детерминированный 32-битный хэш (fmix-подобный), unsigned:
  ```
  h = dayId >>> 0;
  h = Math.imul(h ^ (h >>> 16), 0x45d9f3b);
  h = (h ^ (h >>> 16)) >>> 0;
  index = h % answers.length;
  ```
  MVP **допускает повторы** слов (гарантируется только детерминизм). Критерий теста —
  воспроизводимость (`dayId` → тот же индекс), не отсутствие повторов.
- **practice:** тот же хэш от `(dayId, счётчик_партии)` или `Math.random`, с условием «не равно
  сегодняшнему daily-слову»; на начисление не влияет.
- Ответ хранится в клиентском билде; безопасность — не секретность слова, а серверная перепроверка
  правдоподобности (`durationMs`, `guessesUsed`, `dayId`, паттерн статусов в `meta.rows`).

### 3.4. Раскладки клавиатуры

- **RU (кириллица, ЙЦУКЕН, без `ё`):**
  - ряд 1: `й ц у к е н г ш щ з х ъ`
  - ряд 2: `ф ы в а п р о л д ж э`
  - ряд 3: `ВВОД я ч с м и т ь б ю ⌫`
- **UZ (латиница, QWERTY + диграфы):**
  - ряд 1: `q w e r t y u i o p`
  - ряд 2: `a s d f g h j k l`
  - ряд 3 (диграфы, визуально выделены): `oʻ gʻ sh ch ng`
  - ряд 4: `ВВОД z x c v b n m ⌫`
- `⌫` удаляет **целый юнит** (диграф — за один тап). Клавиши-диграфы вводят юнит целиком.

## 4. Поток данных (мост)

```
GAME_READY ──▶ приложение
        ◀── INIT(authToken, apiBaseUrl, locale, sessionId, theme)
[выбор режима]
GAME_START(sessionId) ──▶
[игрок делает попытки; каждая → evaluate; GAME_EVENT: guess_submitted]
GAME_OVER(score, sessionId, durationMs) ──▶   meta: {mode, dayId, guessesUsed, solved, letterUnits}
если mode==='daily': api.submitScore(...) ──▶ {accepted, pointsAwarded}
[Result] REWARD_CLAIM(rewardId, sessionId) ──▶ ◀── REWARD_RESULT{granted, points}
api.leaderboard('soz') ──▶ топ по слову дня
```

- `submitScore` — только `daily`. `practice` шлёт `GAME_OVER` (аналитика), но не начисляет.
- **score:** `solved ? max(0, 10000 − guessesUsed*1000 − min(durationSec, 999)) : 0`. **Max = 9000**
  (1 попытка, 0 сек). Сервер ранжирует лидерборд по score (метрика монотонна по попыткам и времени).
- **durationMs** измеряется от `GAME_START` до `GAME_OVER` (без пауз).
- **Порядок награды:** `submitScore` → `{accepted, pointsAwarded}` = **превью** (валидация + резерв);
  фактическое зачисление — по `REWARD_CLAIM` → `REWARD_RESULT`. Награда 1/день/пользователь на все языки.
- **Лидерборд** per-locale (RU и UZ — разные слова, раздельный рейтинг).

## 5. Локализация и тема

- Локаль приходит в `INIT` (`ru`|`uz`|`en`); переключает словарь строк, раскладку клавиатуры,
  алфавит, список слов. Ноль хардкода пользовательских строк.
- `theme` из `INIT` (primary/secondary/background/fontFamily/logoUrl) применяется поверх дефолтной
  тёмной палитры (Wordle-цвета статусов — брендонезависимые, остаются).
- Шрифт с покрытием кириллица+латиница+`ʻ`, сабсет под глифы; следим за весом.

## 6. Экраны

1. **Сплэш** — лого из `theme.logoUrl` (фолбэк — заголовок игры), короткий.
2. **Меню** — выбор режима (`daily`/`practice`), переключатель языка (если разрешён), кнопка «Как играть».
3. **Игра** — сетка 6×5, клавиатура (локализованная; для `uz` — с диграф-клавишами), подсветка юнитов,
   тряска на невалидном слове, анимация переворота плиток.
4. **Результат** — solved/failed, загаданное слово, стрик 🔥, кнопка «Поделиться» (эмодзи-грид в буфер +
   `GAME_EVENT: share_result`), лидерборд, «Забрать награду» (`daily`+solved).

## 7. Тестирование

- **Юнит (ядро, обязательно):**
  - `tokenizer`: `shahar → [sh,a,h,a,r]`, `oʻrik → [oʻ,r,i,k]`... граничные диграфы, нормализация `ʻ`.
  - `evaluate`: дубли букв (двухпроходный алгоритм), все-correct, все-absent, смешанные.
  - `dailyWord`: детерминизм (один `dayId` → одно слово), распределение по индексам.
- **Интеграция:** мок моста — проверить, что `practice` не вызывает `submitScore`, а `daily` вызывает.
- **WebView-QA (скилл `webview-qa`):** вес, fps, тач, офлайн, отсутствие рекламы/чужой аналитики.

## 8. Обработка ошибок

- Невалидное слово / не 5 юнитов → тряска ряда + тост (локализованный), без траты попытки.
- Сбой сети при `submitScore`/`leaderboard` → мягкий фолбэк (ретрай/оффлайн-сообщение), `GAME_ERROR` в мост.
- Нет `INIT` в вебе (локальная разработка) → дефолтные локаль/тема/`apiBaseUrl`, мок-режим без начисления.

## 9. Риски и открытые вопросы

- **Словари UZ-латиница:** дефицит открытых источников; часть курируется вручную. Лицензия каждого
  источника — через скилл `license-check` в `docs/LICENSES.md` до использования. **Требует согласования
  с сервером:** формула `dayId` и хэш индекса (§3.3) должны быть реализованы идентично на бэкенде.
- **Клипборд в WebView:** запись в буфер часто заблокирована — основной путь шэринга через
  `GAME_EVENT('share_result')` (нативный share хоста), клипборд — фолбэк.
- **`theme.fontFamily` без нужных глифов:** если брендовый шрифт не покрывает кириллицу/`ʻ` —
  остаёмся на бандл-шрифте для игрового поля; брендовый применяем только там, где покрытие есть.
- **`logoUrl` — удалённый ассет** в офлайн-способной игре: грузим лениво, при ошибке/офлайне —
  фолбэк на текстовый заголовок; не блокируем старт.

## 10. Доступность (a11y)

- **Дальтонизм:** не полагаемся только на цвет. Опция «high-contrast»/паттерн-режим (оранжевый+синий
  вместо зелёный+жёлтый), плюс иконка-статус на плитке при включённой опции. На старте — минимум
  переключатель палитры в меню.
- Тап-таргеты клавиш ≥ 40px; поддержка масштабирования шрифта ОС; фокус-навигация для веб-версии.

## 11. Разрешение замечаний ревью (2026-07-24)

Итоги ревью спеки, зафиксированные как решения:

- **Хэш и `dayId`** — запинены явными формулами (§3.3), реализация клиент == сервер.
- **Max score = 9000** (не 8001), клампим score в ≥0 (§4). Сервер ранжирует по одной метрике score.
- **Схема словарей** — JSON-массивы нормализованных строк, `answers`/`allowed` дизъюнктны,
  `has()` = объединение (§3.1).
- **Диграфы:** жадный разбор — единственный авторитет; `s+h` всегда = `sh`. Слова с раздельными
  `s`+`h` / `n`+`g` в MVP не поддерживаются (курация ответов). Backspace удаляет юнит целиком.
- **`ё` → `е`** нормализуется (клавиши `ё` нет).
- **Локаль строго из `INIT`**, внутриигрового переключателя языка в MVP нет (снимает рассинхрон
  daily/награды между языками). Лидерборд per-locale; награда 1/день/пользователь на все языки.
- **`meta.rows`** содержит юниты + паттерн статусов каждой попытки (для серверной проверки).
- **Персистентность daily** в `localStorage` + анти-реплей ради награды; обработка `PAUSE`/`RESUME`.
- **Порядок награды:** `submitScore` = превью/валидация; зачисление по `REWARD_CLAIM` → `REWARD_RESULT`.
- **`durationMs`** — от `GAME_START` до `GAME_OVER`.
- **Раскладки клавиатуры** RU/UZ зафиксированы (§3.4).
- **EN** — вне рамок MVP (задел в i18n не должен ломать выбор раскладки/алфавита по локали).

## 12. Вне рамок (YAGNI для MVP)

- Несколько длин слова (только 5).
- Полноразмерные словари (пока MVP-курасет).
- Кастомный маскот/сложная графика.
- EN-локаль (задел есть, наполнение позже).
