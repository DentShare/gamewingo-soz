# Инструкция: на чём делать игры для финтех-приложения и где брать шаблоны

Внутренний документ intellica_admin · июль 2026

Цель: встраиваемые HTML5-игры для WebView внутри приложения финтеха. Игры лёгкие, казуальные, с привязкой к баллам/наградам клиента.

---

## 1. Основной стек (рекомендация)

**Phaser 4 + TypeScript + Vite → хостинг Vercel → бэкенд FastAPI + Supabase**

| Слой | Технология | Почему |
|---|---|---|
| Игровой движок | **Phaser 4** (апрель 2026, лицензия MIT) | Стандарт индустрии HTML5-игр, лёгкий рантайм для WebView, огромное число шаблонов и примеров, API отлично знаком Claude Code |
| Язык / сборка | TypeScript + Vite | Наш текущий стек, официальные стартеры Phaser именно под Vite |
| Хостинг игр | Vercel | Уже есть аккаунт и процессы; игра = статический билд |
| Бэкенд (баллы, лидерборды) | FastAPI + Supabase | Наш стек; серверная валидация результатов, RLS для мультитенантности |
| Связь с приложением | WebView + JS-мост (`postMessage`) | Тот же паттерн, что Telegram Mini Apps — опыт переносится напрямую |

### Как стартовать проект

```bash
# официальный интерактивный генератор — выбираешь Vite + TypeScript
npm create @phaserjs/game@latest

# или сразу клонировать официальный стартер
git clone https://github.com/phaserjs/template-vite-ts my-game
```

Официальные стартеры лежат в организации **github.com/phaserjs** — есть `template-vite`, `template-vite-ts`, `template-react`, `template-vue`, `template-webpack` и другие. Для наших целей достаточно `template-vite-ts`: чистый Phaser без обвязки фреймворком.

### Альтернативы и когда их брать

| Инструмент | Когда брать | Когда НЕ брать |
|---|---|---|
| **PixiJS** | Нужен только рендер и максимальный контроль (кастомные анимационные механики) | Обычные казуалки — Phaser даёт больше из коробки |
| **GDevelop / Construct 3** | Очень простая игра из готового исходника стора, no-code правки | Когда нужна глубокая интеграция с API — экспортный код неудобно дорабатывать |
| **Cocos Creator** | Сложные игры с богатым редактором сцен | Избыточен для казуалок, новый инструмент в поддержке |
| **Unity WebGL** | Практически никогда для WebView | Билды 20–50 МБ, долгая загрузка, плохо на слабых Android |

Правило: **весь каталог на одном движке (Phaser)**. Один SDK-мост, один пайплайн сборки, один набор навыков.

## 2. Где брать шаблоны и исходники игр

### 2.1. Официальная экосистема Phaser (бесплатно, MIT)

- **phaser.io** — сам движок, документация, каталог интеграционных шаблонов
- **github.com/phaserjs/examples** — сотни мини-примеров механик (физика, свайпы, частицы, таймеры); конструктор, из которого собираются свои игры
- **phaser.io/news** — регулярно публикуют комьюнити-шаблоны и полные игры с исходниками (включая мультиплеерные стартеры на Colyseus)
- **Phaser Editor** (phaser.io) — визуальный редактор сцен со своими стартер-проектами (платформер, point-and-click и др.)

### 2.2. Open-source игры на GitHub (бесплатно, проверять лицензию)

Готовые игры, которые форкаем и ребрендим:

- **github.com/gabrielecirulli/2048** — оригинальный 2048, лицензия MIT. Десятки Phaser-портов рядом
- **github.com/topics/html5-game**, **github.com/topics/phaser** — постоянный поток кандидатов; фильтровать по звёздам и лицензии
- **js13kgames.com** (+ github.com/js13kGames) — конкурсные игры до 13 КБ; идеальный вес для WebView, многие с открытым кодом
- **github.com/EnclaveGames/Enclave-Phaser-Template** — мобильный каркас: меню, прелоадер, настройки, portrait/landscape, PWA
- Поиск по запросам: `phaser match-3`, `phaser quiz`, `phaser runner`, `wheel of fortune js` — с фильтром `license:mit`

Чеклист перед форком — в разделе 4.

### 2.3. Платные исходники — buy & rebrand

Когда нужен готовый арт, звук и полишинг сразу:

| Площадка | Цена | Что там |
|---|---|---|
| **codecanyon.net** → HTML5 → Games | $15–80 за игру | Тысячи игр с полным исходником, графикой и звуком: puzzle, arcade, quiz, wheel of fortune. Главный источник для быстрого набора каталога |
| **itch.io** → Game assets → Templates / Source code | $5–40 | Инди-исходники и шаблоны, часто на Phaser; лицензия у каждого своя — читать |
| **Construct 3 Asset Store**, **GDevelop Asset Store** | $10–60 | Исходники под конструкторы с экспортом в HTML5 |
| **MarketJS** и аналогичные B2B-студии | от $500 | White-label игры «под ключ» — вариант для эксклюзивной флагманской игры клиента |

Важно на CodeCanyon: **Regular License** — 1 конечный продукт, бесплатный для пользователей; **Extended License** — если у пользователей платный доступ. Для приложения банка обычно достаточно Regular (пользователи не платят за игры), но фиксируем это письменно в реестре.

### 2.4. Ассеты для ребрендинга (графика, звук)

- **kenney.nl** — огромная библиотека спрайтов, UI-китов, звуков. Лицензия CC0: бесплатно, без указания авторства, безопасно на 100%
- **craftpix.net** — платные и freemium паки (персонажи, фоны, тайлсеты), коммерческая лицензия включена
- **opengameart.org** — бесплатный архив; лицензии смешанные (CC0 / CC-BY / GPL) — фильтровать и фиксировать
- **itch.io/game-assets** — паки от инди-художников, $5–30
- **AI-генерация** (SDXL через Replicate, Recraft для векторов) — уникальные спрайты в фирменном стиле финтеха: маскот, иконки, промо-экраны. Это наше отличие от «просто перекрашенного шаблона»

## 3. Лицензии: краткая шпаргалка

| Лицензия | В закрытый коммерческий продукт | Условие |
|---|---|---|
| MIT / Apache 2.0 / BSD | ✅ Да | Сохранить файл лицензии и копирайт автора в коде |
| CC0 | ✅ Да | Без условий |
| CC-BY | ✅ Да | Указать автора (экран «Об игре») |
| CC-BY-NC | ❌ Нет | Запрет коммерческого использования |
| GPL / AGPL | ❌ Нет | Обязывает раскрыть исходники продукта — исключаем полностью |
| CodeCanyon Regular | ✅ Да, 1 продукт | Конечный продукт бесплатен для пользователей |
| CodeCanyon Extended | ✅ Да, 1 продукт | Если доступ к продукту платный |

**Обязательная практика:** реестр лицензий (таблица: источник → лицензия → условия → дата проверки) по каждому шаблону и ассету. Реестр входит в поставку клиенту — это снимает их юридические вопросы и повышает нашу цену как подрядчика.

## 4. Чеклист выбора шаблона (перед форком/покупкой)

- [ ] Лицензия позволяет закрытый коммерческий продукт (см. раздел 3)
- [ ] Движок Phaser 3/4 или чистый JS/Canvas (не Unity, не Flash-порт)
- [ ] Вес билда < 5 МБ (лучше < 2 МБ) — быстрая загрузка в WebView
- [ ] Работает в мобильном браузере: тач-управление, portrait-режим
- [ ] Код читаемый: TypeScript или аккуратный ES6+, без минифицированных «исходников»
- [ ] Нет жёстко вшитой рекламы/аналитики, которую сложно выпилить
- [ ] Ассеты отделены от логики (легко заменить на брендированные)
- [ ] Репозиторий/товар живой: обновления за последние 1–2 года, issues отвечены

## 5. Pipeline доработки одной игры

1. **Шаблон и лицензия** — выбор кандидата по чеклисту, запись в реестр, форк в наш приватный GitHub
2. **Ребрендинг** — ассеты (Kenney/CraftPix/AI-генерация), палитра и шрифты из брендбука клиента, локализация RU/UZ, сплэш-экран
3. **Финтех-слой** — JS-мост, начисление баллов через API, лидерборд, стрики. Скелет моста:

```typescript
// game-bridge.ts — единый для всех игр каталога
type BridgeEvent =
  | { type: 'GAME_READY' }
  | { type: 'GAME_OVER'; score: number; sessionId: string }
  | { type: 'REWARD_CLAIM'; rewardId: string };

export function sendToApp(event: BridgeEvent) {
  // iOS WKWebView / Android WebView / web-фолбэк
  (window as any).webkit?.messageHandlers?.gameBridge?.postMessage(event)
    ?? (window as any).AndroidBridge?.onGameEvent(JSON.stringify(event))
    ?? window.parent.postMessage(event, '*');
}

// приложение передаёт auth-токен при инициализации;
// начисление баллов игра НЕ делает сама — только отправляет
// результат на FastAPI, где серверная валидация и антифрод
```

4. **QA в WebView** — реальные устройства iOS/Android, бюджетные телефоны, офлайн-режим
5. **Деплой** — билд на Vercel + запись в манифест каталога; новые игры добавляются без релиза приложения клиента

С Claude Code шаги 2–3 автоматизируются через SPEC.md на каждую игру: описываем механику, бренд и события моста — агент делает остальное. Реалистичные сроки на игру: **3–10 дней** в зависимости от механики.

## 6. Ограничения, о которых помнить

- **App Store Guideline 4.7** — HTML5-игры внутри приложения допустимы, но только без реальных денег. Держимся строго виртуальных баллов и кэшбэка внутри программы лояльности
- **Никаких денежных призов и «выводов»** — любая механика с выигрышем денег = лицензия на азартные игры
- **Производительность** — тестировать на слабых Android; целевой бюджет: загрузка < 3 сек на 3G, стабильные 60 fps на устройстве за $100
- **Античит** — результат игры валидируется на сервере (лимиты по времени сессии, максимально возможный счёт, частота наград)
